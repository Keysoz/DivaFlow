# Apps

- `cloud-api/` — chat, AI, orders, Control Room API, Telegram bot, workers (cloud node).
- `local-api/` — store gateway and Ops/POS API; the only component that talks to ERPNext (store node). E-12 skeleton: `/health`, item-by-barcode, counter rules (bearer auth).
- `ops-pwa/`, `control-room/`, `mini-app/`, `market-worker/` — arrive with their tasks (E-13, PUB-04, M-01, G).
